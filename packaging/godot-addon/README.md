# Orbital Movement Gdextension GDExtension

Godot 4 addon for orbital_movement_gdextension.

## Installation

1. Download `orbital_movement_gdextension-<version>.zip` from your project's releases.
2. Extract the `orbital_movement_gdextension` folder into your Godot project's `addons/` directory.
3. Open your project in Godot. The extension loads when Godot finds the `.gdextension` file.

## Requirements

- Godot 4.3 or later.
- Supported platforms: Linux (x86_64), Windows (x86_64), macOS (Apple Silicon).

## Demo

Download `orbital_movement_gdextension-demo-<version>.zip`, extract anywhere, and open `project.godot` in Godot.
